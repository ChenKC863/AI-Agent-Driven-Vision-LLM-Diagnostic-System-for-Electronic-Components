# AI-Visual-Recognition-and-LLM-Intelligent-Diagnostic-System-for-Electronic-Components
An on-premises AI diagnostic system for electronic components, integrating a custom MobileNetV3 classifier (exported to ONNX) with a C++ inference engine, local LLM (Ollama), and a LangGraph agent for workflow orchestration, human-in-the-loop review, and fault-tolerant diagnostics.
